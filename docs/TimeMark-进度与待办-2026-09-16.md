  - 根因 2（点不开）：双击时第二击落在弹出的遮罩上立即关闭 = 感知"没打开"。修复：openedAtRef 记录打开时刻，遮罩 300ms 内点击不关闭；整卡可点（原来只有头部/汇总行可点，点进度条无反应也是"点不开"的一部分）。
  - 附加：详情打开时 Esc 关弹窗（capture 阶段 stopPropagation，防上层同时切回聚焦视图）。
  - 验证：双 tsc EXIT=0；asar createPortal + index-6eDNlKUV 命中。**最新 exe = `release19/`**（release18 及更早为旧版）。

## 四、踩坑备忘（避免重复踩）

- WorkBuddy 环境：shell 输出捕获不稳 → 结果写文件再 Read；`ELECTRON_RUN_AS_NODE=1` 全局存在 → 启动 Electron 前必须清。
- Electron：无 GPU/受限环境用 `--in-process-gpu` + `--disable-gpu-sandbox`（仅 disableHardwareAcceleration 不够）；preload.ts 与 IPC 面必须同批更新。
- sql.js：多语句 DDL 逐条执行；`value` 是 H2 保留字（meta 表列名用 val）。
- Spring Boot 打包时 jar 被运行中进程锁住 → Windows 重建前先停 java。
- 客户端 `__run` 标记在 **row 内**（不是 op 顶层），服务端运行状态校验据此判断。
- systemd/环境变量里的 `SERVER_PORT` 会被宿主环境污染 → 用专属名 `TIMEMARK_SERVER_PORT`。
