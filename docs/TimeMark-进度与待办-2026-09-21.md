## 三、踩坑备忘（新增部分）

- **Cloudflare API + curl**：HTTP/2 流重置会导致 `curl error 92`，acme.sh 调用前写 `echo "--http1.1" > /root/.curlrc`。
- **acme.sh + sudo -E**：`HOME` 歧义会让 `account.conf` 写错位置、`--set-default-ca` 不生效并回退 ZeroSSL 失败；部署脚本里 `export HOME=/root`。
- **国内拉 GitHub 常被重置**：acme.sh 从 Gitee 镜像优先 clone。
- **nginx 1.18 不支持 `http2 on;` / `quic on;` 新语法**，用 HTTP/1.1 足够。
- **腾讯云未备案域名**：80/443 入向被拦截，非标端口（本项目 18443）可通行。
- **Android 12+ 前台服务**：后台启动抛 `ForegroundServiceStartNotAllowedException`，重试需退避（否则每 2~15s 空转耗电）。
- **Room 事务**：写库与 pending_ops 入队必须同事务，否则进程在两条语句之间被杀会出现「本地改了却永不同步」。
- **change_seq 全局自增**：换账号登录必须同时清零 pull 游标与 pending_ops，否则新账号历史永远拉不到、旧账号残留队列会把数据推到新账号名下。
- **标签配色**：必须按 UTF-16 码元求和而非码点，否则代理对（增补平面）字符在三端取到不同颜色。
